# C Programming Practice

A collection of C programming exercises completed while building programming fundamentals. This repository records learning progress through small, independent programs rather than a single production application.

## Topics

- Variables, data types, operators and type conversion
- User input and output
- Conditional statements and loops
- Basic arithmetic and problem solving
- Bitwise operations

## Getting started

Each source file is intended to be explored individually. Compile a selected C file with a C compiler, such as GCC:

```bash
gcc 01_first.c -o first
./first
```

On Windows, run the generated executable using the appropriate command for your shell.

## Purpose

Practice problem-solving, understand core programming concepts and build a stronger foundation for data structures and software development.
